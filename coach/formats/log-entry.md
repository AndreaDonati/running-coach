# Formato: voce di log

Si aggiunge in coda alla sezione **Log Allenamenti Completati** del file
settimana, una per seduta svolta.

```markdown
### [GIORNO DD/MM] — [Tipo] [distanza effettiva]
- **Effettivo**: [distanza] km, [passo medio]/km, FC [media] bpm, D+ [m]
- **Delta**: [+/- km, +/- sec/km rispetto al pianificato]
- **Note coach**: [valutazione breve; effetto sui giorni rimanenti, se c'è]
```

Regole:

- Le voci gia' scritte **non si modificano**: si aggiunge in fondo.
- Il **Delta** e' sempre rispetto alla seduta pianificata per quel giorno. Se
  non era pianificata niente, scrivilo: e' un'informazione, non un errore.
- Le **Note coach** dicono qualcosa solo se c'e' qualcosa da dire. Se la seduta
  e' andata come previsto, una riga basta.
- Se emerge un segnale di fatica o dolore, va detto qui **e** in Aggiustamenti
  Attivi.
